# Blinkit Sales Analysis in Python

## Project Overview
This project analyzes Blinkit sales data to identify key business insights, sales trends, and customer purchasing patterns using Python-based data analysis techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Sales Trend Analysis
- Product Category Analysis
- Outlet Performance Analysis
- Data Visualization

## Key Insights
- Identified top-performing product categories.
- Analyzed sales distribution across outlet types.
- Explored factors affecting product sales.
- Generated visualizations to support business decision-making.
